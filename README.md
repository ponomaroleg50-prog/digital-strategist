# Oleg | CDTO · AI & Digital Transformation 🚀

### Соединяю стратегию бизнеса, людей и технологии

Использую управленческий опыт, чтобы понимать реальные проблемы заказчиков, объяснять возможности искусственного интеллекта простым языком и организовывать внедрение решений с понятной бизнес-ценностью.

**Мой подход:** диагностика бизнес-задачи → поиск точек роста → концепция AI-решения → подбор исполнителей → внедрение → оценка результата.

> Технологии — инструмент. Эффективность и рост бизнеса — цель.

## Направления и компетенции

- **Digital transformation:** стратегия, анализ процессов, формирование требований, управление проектами и подрядчиками.
- **AI assistants & bots:** Telegram-боты, клиентские ассистенты, сценарии продаж и поддержки.
- **LLM integrations:** OpenAI API, prompt engineering, tool/function calling, RAG, корпоративные базы знаний.
- **Automation:** n8n, Make, CRM, REST API, webhooks.
- **Delivery:** постановка задач техническим специалистам, проверка результатов, развитие команды фрилансеров.

*Технологии выше обозначают направления специализации и планируемых решений; практический опыт подтверждается только завершёнными опубликованными проектами.*
